# Design Portfolio

A minimalist design portfolio built with pure HTML and CSS, deployed via GitHub Pages.

## Features

- Clean, dark-themed UI
- Responsive layout
- GitHub Actions auto-deploy

## Tech Stack

- HTML5
- CSS3
- GitHub Pages
- GitHub Actions

## Local Development

```bash
git clone git@github.com:cat451814/design-portfolio.git
cd design-portfolio
# Open index.html in your browser
```
